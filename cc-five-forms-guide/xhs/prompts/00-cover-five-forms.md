# Prompt

A hand-drawn educational infographic cover poster, portrait orientation 3:4, designed for Xiaohongshu (RedNote) feed.

**Background**: warm cream off-white #FAF7F0 with very subtle paper grain texture. Minimal, lots of breathing room.

**Main composition**: a centered 2-3 row arrangement of FIVE hand-drawn icon tiles, each representing one form of an AI coding tool. Tiles have wobbly, slightly-irregular hand-drawn outlines (ink black #0E1116, NOT pure black), gentle off-white fill, faint pencil shading. Below or beside each tile, a small phosphor-green #1AB87C signal dot (1-3 tiles only — not all five — to suggest "options").

The five tiles, top-to-bottom and left-to-right:
1. **Terminal window** — classic three-dot mac terminal header, blinking cursor, monospace lines
2. **Mac desktop app icon** — rounded square app icon with subtle shadow
3. **Browser window** — URL bar + tab + simple page silhouette
4. **VS Code editor tab** — file tree + code lines + tab indicator
5. **Code brackets `</>`** representing SDK/API — angular brackets with a tiny gear

Tiles arranged in a slightly playful, non-rigid grid (e.g. 2 + 3 staggered, or 3 + 2). Hand-sketched connecting hairlines or arrows between tiles in graphite gray #3A4151, very thin, suggesting they are siblings of one family.

**Typography**:

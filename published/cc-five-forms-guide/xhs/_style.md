# 共用风格规范（每张 prompt 引用此处）

**Aspect**: portrait 1024×1536 (XHS feed safe ratio).
**Style**: hand-drawn educational infographic, Notion-style flat illustration, sketch-notes vibe; wobbly imperfect outlines (NOT machine-perfect), pencil hatching, very subtle paper grain, generous whitespace, editorial poster feel.

**Strict palette (do NOT add other hues)**:
- Background: warm cream #FAF7F0
- Outlines / main title: ink black #0E1116 (never pure #000)
- Subtitle / body labels / watermark: graphite gray #3A4151
- Accent / signal dots / CTA / wavy underlines: phosphor green #1AB87C
- Cool thin connectors: misty blue #9CB4CC
- Shadow / muted blocks: warm taupe #6E6259

**Typography rules**:
- Main title: large bold sans-serif, ink black #0E1116
- Subtitle / labels: graphite gray #3A4151
- Chinese glyphs MUST render correctly, no garbled characters, no fake-looking CJK, kerning correct
- Single line ≤ 10 Chinese chars; total visible text ≤ 40 chars per image

**Bottom-right watermark**: small text "雷码工坊笔记" graphite gray #3A4151 at ~60% opacity, sans-serif, ~6% width, ~4% margin from edges. Chinese glyphs correct. No icon, no border.

**Forbidden**: purple gradients, neon, orange/coral, pure black, photographic realism, 3D cartoon, marketing-hero, glow effects, code paragraphs, English ALWAYS/NEVER lists, fake CJK.
